使用说明

基本操作
  • 顶部：新建任务 · 新增区块 · 全部任务 · 导入/导出 · 统计 · 回收站 · 归档
  • 右侧图标：🔔到期 · 📅日历 · 🎨主题 · ⚙设置 · ❓帮助 · 👤登录
  • 点击任务条编辑详情，勾选即完成
  • 任务可拖拽到其他区块 · 🗑删除移入回收站
  • 已完成点 归档 移入归档区
排序 & 标签
  • 标题栏 ↕ 默认 / 题 标题 / 期 日期 / 要 重要性 / 部 部门
  • 点击切换排序方式，再点切换升降序
  • 添加标签（逗号分隔），彩色显示与筛选
批量操作
  • 区块 📋 或「全部任务」打开列表视口勾选操作
  • 工具栏：移动/改状态/改截止/改重要性/删除
  • 支持全选当前页 / 全选全部
主题配色
  • 🎨 打开主题选择器，6 套主题可选
  • 支持浅色/深色模式切换
账号与云端同步
  • 👤 登录，支持 Google / GitHub / 邮箱注册
  • 登录后自动同步，多设备数据合并不丢失
  • 未登录数据存本地，登录后云端合并
近期到期提醒
  • 🔔 查看近期到期任务，表头可排序
  • 提前天数可在设置中配置（默认3天）
任务日历
  • 📅 打开日历，显示各日期任务数量
  • 点击日期可快速创建任务
周期性任务
  • 设置重复周期：每天/每周/每月/每年
  • 完成后自动生成下一周期任务
导入导出
  • 导出：按区块/状态/重要性筛选导出 JSON / Excel
  • 导入：可覆盖替换全部或追加合并
  • JSON 互通，Excel 支持跨工具编辑
回收站
  • 删除的任务移入回收站，可恢复或永久删除
  • 支持「恢复全部」或「清空回收站」
系统设置
  • ⚙ 双栏布局：布局/显示/提醒 + 备份/去重/标签
快捷键
  • Esc 关闭弹窗 · Enter 提交表单
