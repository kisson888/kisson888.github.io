使用说明

基本操作
  • 点击顶部「新建任务」或区块内「添加任务」创建任务
  • 点击任务条即可编辑任务详情
  • 勾选复选框标记完成，点右侧 🗑 删除（移入回收站）
  • 任务条可拖拽移动到其他区块
批量操作
  • 点击区块标题栏 📋 或顶部「全部任务」打开任务列表视口
  • 勾选后使用工具栏：移动/改状态/改截止/改重要性/删除
  • 可按状态筛选后批量选中，支持全选当前页 / 全选全部
导入导出
  • 导出：按区块/状态/重要性多维度筛选后导出 JSON 或 Excel
  • 导入：预览导入概况，可选覆盖（替换全部）或追加（合并新增）
  • JSON 格式支持导入导出互通，Excel 支持跨工具编辑
回收站
  • 删除的任务移入回收站，可逐一恢复或永久删除
  • 支持一键「恢复全部」或「清空回收站」
数据安全
  • 所有数据存储在浏览器本地，不会上传任何服务器
  • 设置中可配置自动存档（频次/保留份数/存储标识）
